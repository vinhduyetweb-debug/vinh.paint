# Bé Tô Màu - HTML Static PWA

## Tính năng
- Dùng trên điện thoại/iPad
- Upload ảnh từ máy
- Chuyển ảnh thành tranh nét chì
- Tô màu bằng cọ
- Gôm để tẩy màu
- Hoàn tác
- Làm lại ảnh chưa tô
- Lưu ảnh PNG
- Deploy Vercel dạng HTML tĩnh

## Deploy Vercel
Giải nén thư mục rồi kéo thả vào Vercel, hoặc chạy:

```bash
npm i -g vercel
vercel --prod
```

Không cần build.
